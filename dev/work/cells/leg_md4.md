## 4. Source models — resolved before any target extraction
Source prerequisites are checked first, so a missing asset stops the run before expensive target work:
- **Feature schema.** `LEGACY_FEATURE_POLICY='original_rule'` applies the original scripts' column rule (all source columns except keys and their exclusion list). Columns with no validated MIMIC/eICU adapter stop the run *before training*. EtCO2, SaO2, TroponinI and Hct cannot be supplied by the target adapter and stay missing (never TroponinT/PaO2 surrogates); they are listed in every result row.
- **Source representation.** The official PSV files are sparse; the cleaned CSV used by the original scripts ("previous values gpbyID") appears to be forward-filled within patient. This changes the original missingness/`_tslm` features, so the target adapter must reproduce the same representation. It is measured from the source data (`source_preflight.json`) or declared via `HISTORICAL_SOURCE_REPRESENTATION`; ambiguous or backward-filled sources are refused.
- **Units.** FiO2 units (PhysioNet: fraction; MIMIC/eICU: percent) are detected from source data or declared.
- **Threshold and alarm policy.** The original scripts chose thresholds on validation data with an *hourly* (non-latched) policy but evaluated test data with a latched, backdated first alarm. This notebook uses the hourly policy for both selection and external evaluation and refuses bundles whose declared policy differs from their threshold-selection policy. Persistence alarms (if declared) fire when confirmed, never backdated.
- **Probabilities.** Outputs are PhysioNet *step-label* probabilities (label from onset − 6 h onward), not calibrated six-hour incident risk. Historical models were never calibrated (identity); reproductions fit a source-validation Platt map for reporting only.

Reproduction smoke caps the PSV sample at 1,600 stays (CSV: a bounded prefix) and stops if either class has < 12 stays. Full reproduction trains 3 OSTA seeds (50 epochs, patience 10) and 1 CNN (30 epochs, patience 7) with the original architectures — a long GPU job you launch yourself. Each bundle records the source-internal test utility as a fidelity check against historically reported numbers (never used for tuning).
